Projet construit à partir de la version initiale, en utilisant uniquement la communication parent/enfant (@Input / @Output)

- Recherche par marque ou modèle, filtre par prix, tri, filtre par type de carrosserie (avec compteurs en temps réel)
- Fenêtre de détails de chaque voiture avec contact WhatsApp
- Anglais / français / arabe (mise en page de droite à gauche)
- Mode jour / nuit, animation d'introduction, tampon « Vendu »
- Nouveau design (thème concessionnaire de luxe), en-tête et pied de page
